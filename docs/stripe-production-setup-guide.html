TutorHub • Stripe Production Setup Guide

Step-by-Step Checklist to Go Live with Stripe Connect & Billing

Production • Live Mode
Before You Begin: Turn OFF Test Mode in the Stripe Dashboard using the toggle in the top-right corner. All actions below must be completed in Live Mode.
1
Activate Your Live Stripe Account & Platform Profile

To accept real money and onboard tutors on Stripe Connect, Stripe requires verified platform business credentials:

  1. Log in to dashboard.stripe.com and toggle Test Mode OFF.
  2. If prompted, complete Account Activation:
    • Business Details: Legal business name, business address, and Tax ID (EIN, VAT, GST, PAN, etc.).
    • Bank Account: Enter the bank account where platform revenue (Pro subscriptions) will be deposited.
    • Representative: Verify identity details (ID/Passport) of the primary account owner.
  3. Go to Settings → Connect → Platform profile and configure:
    • Branding: Add your platform logo, icon, and brand colors (used in Stripe onboarding & emails).
    • Support details: Support email address and public website URL (https://yourdomain.com).
2
Enable Accounts v1 Support & Verify Connect Settings

TutorHub creates Express accounts programmatically using Stripe's API. Ensure policy compatibility:

  1. Go to Settings → Developers → API policies:
    Direct link: https://dashboard.stripe.com/settings/developers/api-policies/feat_accounts_v1_support
  2. Click the edit pencil next to Accounts v1 support and select Enable.
  3. Go to Settings → Connect:
    • Account types: Ensure Express accounts are enabled.
    • Business model: Direct charges (buyers pay tutors directly).
3
Get Live API Keys

Generate your live environment credentials:

  1. In the top search or navigation, go to Developers → API keys (in Live mode).
  2. Copy the Publishable key (starts with pk_live_...).
  3. Under Standard keys (or Secret keys), click Create secret key:
    • Name: TutorHub Production Server
    • Permissions: Select Full access (required for managing Connect accounts & subscriptions).
  4. Copy the secret key immediately (starts with sk_live_...).
4
Create the Live "TutorHub Pro" Subscription & Customer Portal

Set up the live recurring subscription product for tutors:

  1. Go to Product catalogue → Add product:
    • Name: TutorHub Pro
    • Description: Unlimited bookings, custom domain, and priority listing
    • Pricing model: Flat fee • Recurring
    • Price: Set your production monthly price (e.g., €19.00 EUR or $19.00 USD)
    • Billing period: Monthly
  2. Click Save product.
  3. Open the created product, go to the Pricing section, and copy the Price ID (starts with price_...).
  4. Activate the Customer Portal:
    • Go to Settings → Billing → Customer portal.
    • Enable customers to: Cancel subscriptions, Update payment methods, and View invoice history.
    • Click Save changes / Activate.
5
Configure Live Webhook Endpoints

In production, Stripe sends HTTP POST requests directly to your live production domain:

  1. Go to Developers → Webhooks → Add endpoint.
  2. Endpoint URL: https://your-domain.com/api/webhooks/stripe
  3. Listen to: Choose Events on connected accounts (or select Both account and connected accounts).
    Critical: TutorHub processes student → tutor bookings which occur on the tutor's Connected account. The webhook must receive Connected account events!
  4. Click Select events to listen to and check the following 6 events:
Event Name What TutorHub Does
checkout.session.completed Confirms lesson bookings & packages, and activates the Pro subscription for tutors.
checkout.session.expired Fails abandoned booking sessions so reserved calendar slots are freed.
charge.refunded Marks lesson payments as refunded in the database.
account.updated Detects when tutor completes Stripe onboarding and marks payouts enabled.
customer.subscription.updated Maintains active/past-due state for tutor Pro subscriptions.
customer.subscription.deleted Downgrades tutor back to the Free plan when their subscription cancels.
  1. Click Add endpoint.
  2. Under Signing secret, click Reveal and copy the secret (starts with whsec_...).
6
Production Environment Variables Reference

Add these environment variables to your production hosting provider (Vercel, Railway, Render, VPS):

# --- App Domain ---
NEXT_PUBLIC_APP_URL=https://your-domain.com

# --- Live Stripe Configuration ---
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_your_actual_publishable_key
STRIPE_SECRET_KEY=sk_live_your_actual_secret_key
STRIPE_WEBHOOK_SECRET=whsec_your_actual_production_webhook_secret
STRIPE_PRO_PRICE_ID=price_your_actual_live_pro_price_id
7
Pre-Launch Verification Checklist
  • [ ] Tutor Onboarding: Log in as a real tutor, click Connect Stripe, and verify completion of real Express onboarding.
  • [ ] Test Booking: Create a test lesson with a real debit/credit card for $1.00 & verify booking confirmation.
  • [ ] Refund Test: In Stripe Dashboard, issue a refund for the $1.00 test charge and verify status updates in TutorHub.
  • [ ] Webhook Monitoring: Check Developers → Webhooks to confirm incoming requests return HTTP 200 OK.
